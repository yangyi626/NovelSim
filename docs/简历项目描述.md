# NovelSim 简历项目描述

以下描述只使用当前仓库已有报告或自动化测试证明的数据。投递时可按版面选用。

## 一句话版

独立实现混合式多 Agent 叙事游戏竖切片：以 LLM 负责高层意图和叙事，以状态机、
受控工具、因果校验和 SQLite 权威事件保证世界一致性，并接入 Unity 3D 运行时。

## 三条简历版

- 设计并实现“LLM 高层决策 + Agent 状态机 + ToolRegistry + 权威
  StatePatch/WorldEvent”的混合架构，覆盖实体、时代技术、Capability、
  Affordance、权限、时空、认知和 Action-Patch 因果校验；G0–G3 消融中
  违规放过数由 `6` 降至 `0`。
- 实现原创密信多 Agent 场景的有限认知、逐跳证据传播、关系演化与确定性联盟，
  9/9 固定案例通过，合法工具、回放、传播和证据链均为 `100%`，非法 Patch、
  未知实体接受、因果越权和认知泄漏均为 `0`。
- 接入 Unity 6.3 LTS 的 NavMesh、交互、物品/对话/联盟 HUD 与可续传事件游标，
  完成 Windows x64 构建和重启恢复；20 局真实 `qwen3.7-plus` 回归完整运行，
  目标成功 `18/20`，45 次调用共 `49,255 Token`，P50/P95 为
  `10.554s/16.469s`。

## 面试项目介绍版

NovelSim 是一个服务器权威的 AI 叙事游戏原型。玩家和 NPC 的自然语言先解析为
候选行动，LLM 不能直接改世界；所有事实变化必须通过工具权限、世界规则和因果授权，
以原子 `StatePatch` 提交为可回放 `WorldEvent`，Unity 再消费事件做 NavMesh
移动与 HUD 表现。项目还实现角色隔离记忆、信息证据链、联盟规则、真实模型
Telemetry、固定场景回归、门禁/记忆消融和 BOOKWORLD 风格盲测。
