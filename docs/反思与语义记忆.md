# 反思与语义记忆

## 目标

情景记忆回答“角色经历过什么”，反思记忆回答“角色从多次经历中形成了什么判断”。

当前实现遵循以下边界：

- SQLite 仍是权威存储；Qdrant 只保存可重建的派生向量。
- 反思只能引用当前角色已经拥有的情景记忆。
- 每条反思至少包含两个不同事件 ID，不能由单一事件升级成长期结论。
- 推断使用 `suspected_true` / `suspected_false` 等认知强度，不把猜测伪装成客观事实。
- 当前权威认知与旧反思冲突时，写入阶段拒绝；认知后来变化时，召回阶段再次过滤。

## 数据流

```text
有效回合提交
  → 事件投影为角色情景记忆（episodic）
  → 达到反思间隔且至少有 3 条未处理经历
  → 低温 LLM 提炼候选反思
  → Pydantic 结构校验
  → 证据 ID / 实体 ID / 当前认知冲突确定性校验
  → 独立低温 LLM 执行证据蕴含与过度推断评分
  → SQLite 幂等写入 reflection
  → Qdrant 同步派生向量

NPC 决策前召回
  → SQLite FTS5 + Qdrant 混合检索
  → SQLite 权威回查
  → 按当前角色认知过滤过期或相反反思
  → 最多 4 条进入角色上下文
```

## 反思记录

`character_memories` 在原有记忆字段上增加：

| 字段 | 含义 |
|---|---|
| `memory_type` | `episodic` 或 `reflection` |
| `evidence_event_ids_json` | 支撑反思的事件 ID 列表 |
| `claim_fact_id` | 稳定主张 ID，用于同一判断幂等更新 |
| `claim_belief` | 角色对主张的认知极性与强度 |
| `claim_confidence` | 反思置信度 |
| `semantic_score` | 独立审查器给出的证据语义一致性分 |

同一角色、同一 `fact_id` 会映射到稳定的反思来源 ID。后续出现同类证据时更新原记录并合并证据链，不重复堆积同义记忆。SQLite 旧库会自动补列；PostgreSQL Schema 也保留同样字段，但当前运行不依赖 PostgreSQL。

Qdrant payload 同步保存这些元数据，实际命中后仍必须回查 SQLite。

## 触发与配置

`.env`：

```dotenv
MEMORY_REFLECTIONS_ENABLED=true
MEMORY_REFLECTION_INTERVAL=5
MEMORY_REFLECTION_MIN_EPISODES=3
MEMORY_REFLECTION_SEMANTIC_JUDGE_ENABLED=true
MEMORY_REFLECTION_SEMANTIC_THRESHOLD=0.72
```

- 默认每逢世界版本可被 5 整除时检查一次。
- 每个 NPC 至少积累 3 条尚未被反思消费的情景记忆才调用 LLM。
- 生成失败只形成 `memory_warning`，不回滚已经成功提交的游戏回合。
- 语义审查默认失败关闭：矛盾、非直接支持、证据覆盖率低于 0.6 或总分低于 0.72 的候选不会写入。
- 每个角色最多保留 100 条反思记忆；情景记忆仍按原容量策略治理。

## 离线重建

从现有情景记忆生成缺失反思：

```powershell
# 全部存档
.venv\Scripts\python.exe -m engine.rebuild_reflections

# 指定存档
.venv\Scripts\python.exe -m engine.rebuild_reflections --session <session_id>

# 忽略已消费证据并重新审视
.venv\Scripts\python.exe -m engine.rebuild_reflections --session <session_id> --force

# 先从事件/剧情重建情景记忆，再生成反思
.venv\Scripts\python.exe -m engine.rebuild_reflections --session <session_id> --rebuild-episodes
```

该命令会调用 LLM，运行前需要有效的 LLM 配置。它不会改写世界状态或事件链。

## 已验证行为

- 结构化输出、最少证据数、未达阈值不调用模型。
- 证据链和结构化主张持久化。
- 同一事实幂等更新并合并新证据。
- 与权威认知相反的候选反思被拒绝。
- 已存反思在角色认知变化后不会继续进入决策上下文。
- 首次返回空数组时进行一次受约束的二次审视。
- 独立语义审查器已通过真实模型的跨事件证据烟测。
- 真实模型已从“折断刀刃 + 护卫畏惧”提炼出“夜轻歌可能隐藏实力”，并正确绑定 `char_yeqingge`。

## 当前边界

- 反思是角色主观认知，不会直接改写 `WorldState` 中的客观事实。
- 当前按固定版本间隔触发，尚未加入“重要事件立即反思”与异步任务队列。
- 当前语义门禁本身仍依赖模型判断；生产环境可继续加入人工抽检集和本地 NLI 模型交叉验证。
- 删除或修改底层情景记忆后，建议重建反思与 Qdrant 索引。
