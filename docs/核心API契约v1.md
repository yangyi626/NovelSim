# 核心 API 契约 v1

当前稳定契约版本为 `1.0.0`，机器可读清单位于
[`contracts/api-v1.json`](../contracts/api-v1.json)。

## 兼容规则

- `1.x` 内不删除已有路径、HTTP 方法、请求字段或响应字段。
- 可以增加可选请求字段和客户端可以忽略的响应字段。
- 破坏性变更必须提升主版本，并同时保留迁移说明。
- 所有响应返回 `X-NovelSim-Contract: 1.0.0`。
- `/api/meta/contract` 可在运行时查询当前契约和存储边界。

## 权威边界

- `WorldState + WorldEvent` 是运行时权威事实。
- SQLite 是当前世界状态、账户、审计和编译控制面的权威存储。
- Qdrant 只保存可从 SQLite 重建的向量索引。
- Web 服务只创建和控制编译任务；独立 Worker 通过 SQLite 租约领取任务。
- 创作者接口使用 Bearer token；创作、审核决定和发布属于不同权限。

## RBAC

| 角色 | 权限 |
|---|---|
| `creator` | 编辑世界包、管理编译任务、提交审核 |
| `reviewer` | 读取创作内容、批准或驳回、查看审计 |
| `publisher` | 读取创作内容、正式发布、查看审计 |
| `admin` | 账户管理和全部权限 |

审核发布必须按状态机执行，拥有审核权限不自动拥有发布权限。
