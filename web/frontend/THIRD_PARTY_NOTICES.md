# Third-party design reference

The NovelSim simulation console uses the three-column information architecture
of [BookWorld](https://github.com/alienet1109/BookWorld) as a design reference:
world map and character profiles on the left, live story events in the center,
and simulation state panels on the right.

BookWorld is distributed under the Apache License 2.0. NovelSim's Vue components
are a new implementation backed by NovelSim's own API and authoritative world
engine; no BookWorld agent runtime or model prompts are included.

See BookWorld's license at:
https://github.com/alienet1109/BookWorld/blob/main/LICENSE
